MODEL CONNECTION

Bring your models. Keep your control.

Set OPENROUTER_API_KEY in your terminal before starting the dashboard. Credentials stay on the server.

For OpenRouter, set OPENROUTER_API_KEY in the server environment. For a local model, start an API server with a compatible /v1 interface, then enter its loopback address below. Local servers usually need no key; if yours does, set LOCAL_MODEL_API_KEY before starting this dashboard.

npm run dashboard

OpenRouter sends selected review context to its model provider. Local mode sends it only to your configured loopback model server, with no cloud fallback. Use a model server configured for local inference. Keys always stay in the server environment.
