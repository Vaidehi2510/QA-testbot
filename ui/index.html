Bring your models. Keep your control.

Set OPENROUTER_API_KEY in your terminal before starting the dashboard. Credentials stay on the server.

Set your OpenRouter key as an environment variable, then start the workspace:

export OPENROUTER_API_KEY='your-key'
npm run dashboard

Model requests send selected repository context to OpenRouter and its model provider. Choose a specific model and a budget below. Configure the same secret in GitHub Actions when you enable production integration.
